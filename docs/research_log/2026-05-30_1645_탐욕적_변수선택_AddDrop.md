# Research Log

## 2026-05-30 — 탐욕적 변수선택 (Forward-Backward Add/Drop) — 증분신호 일반화

> EV 민감도(`2026-05-30_1600`)의 4조건 게이트를 **수집한 31개 변수 전체**로 일반화.
> 빈 세트에서 forward-backward로 넣었다 뺐다하며, window(2010/2018/2021~)별로 어떤
> 변수가 증분 신호를 갖는지 재발견. **결론: 전 window 공통 견고핵심은 휴일·태양복사·
> 난방(선형+비선형)·냉방도일·습도 — v3c의 기상/달력 핵심과 일치. 추세항(pop/ip/EV)은
> 한계 신호 미약(수렴 후 비유의). 전기차는 세 기간 모두에서 무신호 재확인. AIC-greedy는
> v3c를 못 이김 → 본모델 v3c 유지가 타당.** 본모델·기존 노트북·exog 산출물 불변.

### 대상

- 후보 31개: `exog_daily` 실변수 + 파생(`*_sq`, `*_any`) + EV(`ev_stock`,`ev_flow`).
  제외: `ss_day_n_stations`(메타), `dow`·`month`(원 범주 정수).
- v3c와 동일 차수 `(1,1,2)(1,1,1,7)`·log 타깃·편향보정·train-only 표준화·2025 홀드아웃.
  **독립 스크립트로 self-contained 재현**(기존 모듈 import·수정 없음).
- window(학습 시작연도) ∈ {2010, 2018, 2021} 바깥 루프, 평가 2025 고정 봉인.

### 어떻게 greedy하게 했나 (절차)

**한 줄 요약.** 변수 0개에서 시작해, **"지금 넣어서 가장 도움 되는 변수 1개를 넣고,
넣고 나니 쓸모없어진 변수 1개를 빼고"** 를 더 나아지지 않을 때까지 반복한다.

**무엇을 보고 "도움 된다"고 판단하나 — 게이트.** 한 변수를 후보로 넣었을 때 아래
**세 조건을 모두** 만족해야 채택한다(하나라도 어기면 기각):

| 조건 | 의미 | 왜 |
|---|---|---|
| `ΔAIC < −2` | 모델 정보기준이 2 이상 개선 | "통계적으로 의미 있는 개선"의 표준 임계 |
| `p < 0.05` | 그 변수 계수가 유의 | 우연이 아닌 실제 효과 |
| `VIF < 10` | 기존 변수들과 공선 아님 | 이미 있는 변수의 중복이 아님 |

**단계별 절차** (각 window에서 독립 실행):

1. **시작**: 외생변수 0개(빈 세트)로 SARIMA만 적합 → 기준 AIC 기록.
2. **Forward(추가)**: 아직 안 들어간 후보를 *하나씩 전부* 넣어보고 각각 적합 →
   AIC가 가장 좋아지는 후보를 고른다. 그게 게이트(위 3조건)를 통과하면 **채택**.
3. **Backward(제거)**: 현재 들어있는 변수들을 점검 → 새 변수가 들어오면서
   `p>0.05`(무의미해짐)·`VIF>10`(공선 생김)이 됐거나, 빼는 게 오히려 AIC를 낮추는
   변수가 있으면 **제거**. (Forward만 하면 초반에 뽑힌 변수가 나중에 더 좋은 변수에
   가려져도 영영 남는 문제가 생겨 — 이를 교정하는 단계.)
4. 추가도 제거도 없는 라운드가 나오면 **종료**.

선택을 구동하는 지표는 **AIC + 계수 p + VIF**(전부 학습구간 내). **2025 MAE는 게이트가
아니라 OOS 확인용**으로만 기록 — 선택 루프가 홀드아웃을 반복 엿보면 누수가 되기 때문.

**실제 추적 예 (2010~ window, forward 진행):**
```
시작(변수 0개) → 기준 AIC
 +is_holiday   (AIC −22110, p<0.001)   ← 휴일이 가장 크게 개선 (peak 수요 급감)
 +cdd_18_sq    (비선형 냉방, p<0.001)
 +hdd_18_ma7   (난방 7일평균, p<0.001)
 +hdd_18_sq    (비선형 난방, p<0.001)
 +ss_day       (태양복사, p<0.001)
 +cdd_18_ma7   (냉방 7일평균, VIF 9.5 ← 게이트 통과 직전)
 +hm_avg       (습도, p<0.001)
 +ev_stock     (p=0.017로 간신히 통과) → 더는 통과 후보 없어 종료
```

**Backward가 실제로 작동한 예 (2018~ window):** `ta_hourly_max`를 step2에서 채택했지만,
step4에서 `hdd_18_ma7`가 들어오자 중복이 되어 **step5에서 자동 제거**(`-ta_hourly_max`).
이후 `hdd_18_sq`·`ip_total` 등이 다시 추가됨 — 넣었다 뺐다가 실제로 일어남.

**검색 비용 주의.** 후보 31개 × 라운드마다 전부 재적합이라 적합 횟수가 많아, 검색 중에는
`maxiter=50`(빠른 근사 랭킹), 최종 발견 세트만 `maxiter=200`으로 깨끗이 재적합해 보고한다.
이 근사 때문에 마진에서 들어온 변수가 완전수렴 시 비유의로 드러나는 경우가 있다(아래 결과 3·4).

### 최종 결정 / 결과

**window별 발견 세트 (검색 maxiter=50):**
| window | discovered |
|---|---|
| 2010~ | is_holiday, cdd_18_sq, hdd_18_ma7, hdd_18_sq, ss_day, cdd_18_ma7, hm_avg, *ev_stock* |
| 2018~ | is_holiday, cdd_18, ss_day, hdd_18_ma7, hdd_18_sq, hm_avg, *ip_total*, rn_day, heat_feels_th_2day_adv |
| 2021~ | is_holiday, cdd_18_ma3, hdd_18_sq, ss_day, hdd_18_ma7, is_weekend |

**1. 전 window 공통 견고핵심 (p<0.001).** `is_holiday`(−), `ss_day`(태양복사),
`hdd_18_ma7`+`hdd_18_sq`(난방·비선형), 냉방 도일항 1개, `hm_avg`(2/3). 기간 무관 구조 동인 →
v3c 기상·달력 핵심과 일치.

**2. 공선 클러스터 → 대표 1개로 붕괴.** 냉방항이 window마다 `cdd_18_ma7`/`cdd_18`/`cdd_18_ma3`로
교체되는 것은 VIF 게이트가 공선 형제 중 하나만 통과시키기 때문(승자는 기간 노이즈). 계획에서
예측한 거동 그대로.

**3. 추세항 한계 신호 미약.** `pop_total`은 어느 window에서도 미선택.
`ip_total`(2018~)·`ev_stock`(2010~)은 검색(maxiter=50) 마진에서 들어왔으나 **완전수렴
(maxiter=200) 재적합 시 p=0.172·0.823으로 비유의** = 검색-근사 artifact. 추세는 SARIMA
적분항이 이미 흡수.

**4. 전기차 — `2026-05-30_1600` 재확인.** `ev_flow` 전 window 미선택. `ev_stock`은 2010~에서만,
그것도 *다른 추세항이 선택되지 않은 상태의 저-VIF 추세 대체재*로 잠깐 들어왔다 수렴 후
p=0.823으로 사라짐. 독립 신호 아님(추세 공선의 잔향). **세 기간 모두에서 무신호** 확인 →
본모델 미포함 유지.

**5. greedy < v3c (정상).** AIC-from-empty + 엄격 게이트는 보수적·근시안적:

| window | discovered AIC / MAE_2025 (n) | v3c AIC / MAE_2025 (n) |
|---|---|---|
| 2010~ | −23751.9 / 2665.5 (8) | −23830.9 / 2671.0 (14) |
| 2018~ | −10891.5 / 3346.7 (9) | −11001.2 / 2346.3 (14) |
| 2021~ | −6181.3 / 2393.0 (6) | −6350.6 / 2123.3 (14) |

v3c가 전 window에서 AIC 더 낮음. 짧은 window(2018·2021)에선 greedy의 봉인 2025 MAE가
크게 뒤짐(변수 부족). 전체 window(2010~)에선 8개로 v3c(14) MAE 거의 동률 → v3c에 다소 잉여는
있으나 해롭지 않고 짧은 기간 일반화에 도움. **본모델 v3c 유지 타당**을 독립 재확인.
